React JavaScript Practice Explorer

This repository contains React practice projects created using React and Vite.
It includes examples of Props, State, Class Components, and Lifecycle Methods.

Project Folders


1. props-states

This folder contains examples of:
React Props
useState Hook
State Management
Input Handling
Conditional Rendering




2. component-lifecycle
This folder contains examples of React Lifecycle Methods:

componentDidMount()
componentDidUpdate()
componentWillUnmount()

It helps understand component mounting, updating, and unmounting.



3. class-base-components
This folder contains examples of:

Class Components
Constructor
this.state
this.setState()
Event Handling
Form Input Handling
Technologies Used
React
Vite
JavaScript
JSX
CSS
Installation

Clone the repository:



git clone <repository-link>

Move into project folder:

cd pr-1-explorer

Install dependencies:

npm install

Run the project:

npm run dev
